
# Vira Página 📚

O **Vira Página** é um projeto de desenvolvimento web que simula uma vitrine virtual de livros, com uma aparência inspirada em lojas de e-commerce.

O objetivo é apresentar livros de forma organizada, permitindo que os visitantes conheçam os títulos, autores, preços e categorias disponíveis.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Funcionalidades

- Página inicial com apresentação da livraria.
- Catálogo de livros.
- Exibição de capas, autores, preços e descrições.
- Organização por categorias.
- Layout responsivo para diferentes tamanhos de tela.
- Página de cadastro de usuários.

## 📂 Estrutura do projeto

```
ProjetoWeb2UnidadeII/
```

## 💻 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.

Não é necessário instalar dependências.

O projeto está em desenvolvimento e será aprimorado gradualmente com novas funcionalidades, buscando oferecer uma experiência semelhante à de um e-commerce.
